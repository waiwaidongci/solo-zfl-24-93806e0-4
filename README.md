# 赛鸽血统环号登记站

运行：

```bash
npm start
```

访问 `http://localhost:3024`。支持档案、血统查询、转让、归巢成绩记录，以及疫苗台账。

## 页面

- `/`：原有登记站（档案创建、血统查询、转让、归巢成绩），卡片和血统详情展示最近接种与到期提醒，顶部保留进入疫苗台账的入口。
- `/vaccines`：疫苗台账。
  - 登记每只鸽的疫苗名称、接种日期、下次到期日（足环号下拉仅含已登记赛鸽）。
  - 按到期状态（有效期内 / 30 天内到期 / 今日到期 / 已过期 / 无到期日）和日期（截止日期、到期日范围、足环号）查询。
  - 列表按紧迫程度排序（已过期 → 今日到期 → 即将到期），点击记录查看该鸽完整接种台账、最近接种和到期提醒。

## 校验规则

- 日期必须是 `YYYY-MM-DD` 格式的真实日期（拒绝 `2026-02-30`、`2026-13-01` 等），到期日不得早于接种日，无效输入返回 400 与明确中文提示。
- 同一只鸽、同一种疫苗在有效期内不能重复登记（新接种日落入上一针接种日至到期日之间返回 409）；到期日之后可登记新一针。
- 疫苗只能挂在已登记赛鸽上，足环号不存在返回 404。
- 旧版只有日期和名称的疫苗记录自动补空到期日，显示为“无到期日”。

## 主要接口

- `GET /api/pigeons` / `POST /api/pigeons`
- `GET /api/pigeons/:ringNo/relation`
- `POST /api/pigeons/:ringNo/transfers` / `…/races` / `…/vaccines`
- `GET /api/pigeons/:ringNo/vaccines`
- `GET /api/vaccines?status=&asOf=&dueAfter=&dueBefore=&ringNo=`

数据保存在 `data/pigeons.json`，重启后保留。
